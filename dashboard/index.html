How the implied value is built

implied value = TVL × category FDV/TVL multiple × growth factor × breadth factor × launch probability × 7% airdrop share

The multiple is the median market-cap/TVL of the token-bearing protocols in the same category, taken from this very snapshot — the snapshot's own trading protocols calibrate it, no name is hardcoded. Launch probability rises with how long a protocol has run with no token (0.25 fresh → 0.70 mature). Growth is the 7-day TVL change, capped so one wild week cannot dominate. Every row below says “records no token”, never “has none”: the snapshot is DefiLlama’s record, not proof.

Method & limits

  • Board: every genuine pre-token protocol in the snapshot — the full 40-protocol watchlist (TVL ≥ $50M, no token recorded, not a wrapped, staked or bridged product) plus 158 further pre-token protocols the watchlist leaves out, filtered by the same rule the watchlist uses: no token recorded, not a wrapped, staked or bridged product, not a versioned release, not an exchange product. Bridges, CEX desks and liquid-staking wrappers are left out on purpose: they will never launch a token of their own.
  • Implied value is this entry’s own claim, never make.fun’s. It does not predict whether or when a token launches.
  • Farm plans are generic by category and chain, priced with per-chain gas hints; check the protocol’s own docs before moving funds.
  • Snapshot: DefiLlama protocols API, fetched 2026-11-14. The program re-derives everything from the snapshot file, so a future snapshot re-ranks the board on its own.
